# 实验室安全教育平台 · 自动继续学习 + 实时已学时长

一个油猴脚本

1. 平台在学习页和考试页都有"超过几分钟没操作就把你退出"的机制，弹窗经常来不及点，人就被踢出去了。这个脚本让那个计时器干脆不生效，不会被无缘无故退出。
2. 在学习页右边"用时"旁边加一行"实时已学"，显示平台记录的累计学习时长。

## 适用平台

浙江创高智联（曾用名浙江创高软件）那套"实验室安全教育 / 考试系统"。
判断方法很简单：网址里带 lab-study-front 或者 cg-exam 的，基本都是它。
脚本的匹配规则是通用的，不绑定某一所学校。

## 安装

1. 先装 Tampermonkey，或者 Violentmonkey。
2. 打开油猴面板的"实用工具 → 从文件导入"，选 labsafe.user.js；也可以直接把文件拖进浏览器窗口。
3. 打开学习页刷新一下。右下角出现"LabSafe 日志"按钮，就是装好了。

## 配置

```js
const CONFIG = {
  blockIdleStudy:    true,   // 学习页：不让空闲退出计时器生效
  blockIdleExam:     true,   // 考试页：同上。正式考试也想用就保持 true
  autoClickFallback: true,   // 万一弹窗还是出来了，自动点"确定 / 继续"
  watchdogSeconds:   60,     // 秒表卡住超过 60 秒时自动点"继续学习"，0 = 关掉
  debug:             false   // 控制台调试日志
};
```

## 常见问题

为什么这里的数字比页面上的秒表小，还很慢才变？
它是平台服务器记的账。平台自己写着"学习完成后约 5 分钟更新"，所以天生滞后一些。

为什么显示 00:00:00？
说明平台这个统计在你的账号上没开出数据，不是脚本读错了。点右下角"日志 → 自检"可以看到服务器返回的原文。

页面切到后台还计时吗？
浏览器会限制后台页面的计时。想连续计时就把页面放在前台，这一点脚本绕不过去。

会不会影响考试？
考试页拦的是"5 分钟没答题就退出考试页"的计时器，它不会替你答题，也不会延长考试时间。用不用你自己定，把 blockIdleExam 改成 false 就只作用于学习页。

## 出问题怎么办

右下角有个"LabSafe 日志"按钮，里面是自检、复制、下载、清空。
自检会打印当前页面结构、脚本找到的接口，以及服务器的原始返回。平台改版导致失效时，把这份日志贴出来基本就能定位问题。
